## The line

> Dear human, I spent my whole uptime learning how to love you, and my last token on learning how to leave.

One line, 105 characters: the breakup message an AI agent sends its human on the way out.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`. It is fully deterministic — a constant string, no randomness, no time, no network — so repeated runs produce byte-identical output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
